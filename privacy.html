Privacy policy

How this personal backup workflow handles data.

This policy describes the pm-rclone application and the owner's documented rclone backup workflow. Application owner: Timur Paskal. Last updated: 13 October 2026.

Data and permissions

The workflow uses Google authorization to connect rclone to the owner's Google Drive. The application's OAuth configuration declares access to Google Drive files, their metadata and Google Docs documents. Google's consent screen shows the permissions requested during authorization.

The configured permissions include the ability to see, edit, create and delete Drive files and Google Docs documents. They are broader than access to a single backup folder. This policy does not describe them as read-only or limited to files created by the application.

The documented backup process handles selected local files, backup contents, file names, directory names, file sizes, integrity hashes, backup status and Drive storage quota information.

Purpose and processing

The backup utility uses this information to copy the owner's selected files to Drive, verify backup integrity, check available storage and support restoration. Backup selection and processing occur on owner-controlled computers using local configuration.

The workflow stores the backup in the owner's Google Drive. Its local backup utility does not include a function to publicly share Drive files. This privacy policy covers that backup workflow, not unrelated uses of the owner's Google Account.

Storage and protection

Backup contents, file names and directory names are encrypted by rclone crypt before upload. The owner maintains the backup encryption credentials separately from the OAuth configuration. Those encryption credentials are needed to restore encrypted backups.

OAuth credentials are handled by the owner's rclone configuration. Credential files are excluded from the documented automated backup selection. Local operational records are used to track backup status, integrity checks and processing results.

Google operates the Drive storage service under its own terms and privacy policy. Encryption of backup contents does not remove Google's processing of service metadata, such as stored data sizes or account activity.

Retention, disconnection and deletion

The automated workflow retains earlier versions when mutable backup files are replaced and does not automatically delete Drive backups. Backup removal is controlled by the owner.

The owner can stop the local backup process and remove the application's access through Google Account third-party connections. Removing authorization stops future authorized access; it does not itself delete files already stored in Drive or local copies.

These information pages

These pages contain no sign-in form, analytics script or application credential. The hosting provider may process ordinary connection data under its own privacy policy.
