Personal backup utility

A private backup workflow using Google Drive.

pm-rclone is the Google OAuth application used by Timur Paskal for a personal rclone backup workflow. It connects an owner-controlled rclone installation to the owner's Google Drive.

What it does

The workflow copies selected local project files to Google Drive, checks backup integrity and supports restoring those files. The backup utility uses rclone crypt to encrypt backup contents, file names and directory names before storing them in Drive.

The automated workflow checks files before copying them, excludes credential files and keeps previous versions when mutable backup files are replaced. It does not automatically delete Drive backups.

Google Account access

Google authorization is completed on Google's own consent screen. The OAuth configuration currently declares permissions to read and manage Google Drive files, read Drive file metadata, and read and manage Google Docs documents.

These are broad permissions. They are not technically restricted to a single backup folder. The actual requested permissions are shown by Google when the owner authorizes the application.

pm-rclone is intended for the owner's personal backup use. This page is an explanation of the application; it is not a public backup service or a registration page.
